# Checkpoint

`gaca_73.25.pth` is the final full-training checkpoint from the completed rerun. It contains a state dictionary for GaCA with 3,811 output classes and a 512-dimensional fusion representation.

The corresponding Level-4 accuracies are 73.25% on the 243-protein `<30%` subset and 84.91% on the 477-protein `30-50%` subset.
